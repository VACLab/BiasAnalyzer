# BiasAnalyzer
<h1>
  <img src="./assets/logo.png" alt="Project Logo" width="50" style="vertical-align: middle; margin-right: 10px;">
  BiasAnalyzer
</h1>



This is the master repo for the BiasAnalyzer project funded by [NC TraCS](https://tracs.unc.edu/). The project is being developed to help researchers evaluate the statistical validity of study cohorts derived from [OMOP](https://www.ohdsi.org/data-standardization/)-based electronic health record (EHR) data, with a primary focus on identifying, quantifying, and mitigating statistical bias across all types of clinical variables - particularly cohort selection bias. 

The BiasAnalyzer project is composed of multiple open source components. This master repository serves as the gateway to all of its components as summarized below.

| Components           | Repository                                                   |
| -------------------- | ------------------------------------------------------------ |
| `BiasAnalyzerCore`   | [VACLab/BiasAnalyzerCore](https://github.com/VACLab/BiasAnalyzerCore) |
| `BiasAnalyzerVis`    | [VACLab/BiasAnalyzerVis](https://github.com/VACLab/BiasAnalyzerVis) |
| `BiasAnalyzerWidget` | [[VACLab/BiasAnalyzerWidget](https://github.com/VACLab/BiasAnalyzerWidget) |
| `BiasAnalyzerApp`    | [[VACLab/BiasAnalyzerCore](https://github.com/VACLab/BiasAnalyzerApp) |
